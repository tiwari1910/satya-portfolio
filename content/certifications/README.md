Add one JSON file per certification here, for example `aws-solutions-architect.json`:

{
  "title": "AWS Certified Solutions Architect – Associate",
  "issuer": "Amazon Web Services",
  "date": "2027-01",
  "displayDate": "Jan 2027",
  "url": "https://www.credly.com/badges/..."
}

`date` (YYYY-MM) sorts newest first; `displayDate` is what the site shows. Optional `includes` lists courses inside a bundle (see google-ai-professional.json).

The Certifications section appears on the site automatically once this folder has at least one .json file.
